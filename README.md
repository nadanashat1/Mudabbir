# Mudabbir (مدبّر)

An Arabic-language landing page for a smart money-management app, built with HTML and CSS. "Mudabbir" means "planner" - the page presents a personal finance app concept for Arabic-speaking users, fully right-to-left.

## Tech stack

- HTML5
- CSS3

## Getting started

Open `Task5/index.html` in a browser - no build step needed.
